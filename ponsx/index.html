How it works

Connect. View. That's it.

No custody, no approvals beyond a read-only connection, no surprises.

🔗

Real Phantom connect

Uses Phantom's standard connect() API to read your public address only — never a private key, never a transaction signature.

📊

Live on-chain data

SOL balance and token holdings are fetched directly from a public Solana RPC endpoint in real time.

🛡️

Nothing to approve

PonsX never asks you to sign a transaction or approve a spend. Disconnect at any time, from anywhere.
