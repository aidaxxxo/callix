How it works

Before each spin we generate a random server seed and show you its SHA-256 hash (the commit). We can't change the seed afterwards without breaking that hash. The winning number is computed as:

H = HMAC-SHA256(serverSeed, clientSeed:nonce)
result = (first 8 hex of H, as int) mod 37

After the spin we reveal the server seed. Hit Verify to confirm the hash matches and the number was derived exactly as above. You control the client seed, so neither side can predict or fix the outcome.
